# LibraryScraperFix

MoviePilot V2“媒体库刮削（魔改版）”安全增量插件，基于官方 `LibraryScraper 2.1.3`。

## 核心行为

- 默认停用、默认预演，不会在安装后自动写媒体库。
- 不覆盖模式只补齐缺失项，即使 MoviePilot 全局 NFO 策略设为覆盖。
- 全程应用排除路径、强制媒体类型和符号链接保护，包括目录识别失败后的文件回退。
- NFO 中的 TMDB ID 只有在可解析为正整数时才覆盖文件名解析结果。
- 只缓存完整成功的目录；部分成功、未识别和失败目标会在下次任务继续尝试。
- 组合指纹包含文件路径、大小和纳秒修改时间；默认每 7 天完整复核一次。
- 进程内锁、跨热重载文件锁及 MoviePilot 刮削锁共同阻止并发写入。

## 推荐配置

首次使用：停用插件、开启预演、仅配置一个小目录、单次最多处理 `1` 个目标。确认日志和摘要后关闭预演，仍只处理同一小目录。

长期全库：启用增量扫描、仅补齐缺失元数据、每天 `0 3 * * *`、单次最多 `50` 个目标、间隔 `0.2` 秒、重试 `1` 次、完整复核 `7` 天、发送运行摘要。

`单次最多处理目标=0` 表示不限量。`下次忽略增量缓存` 和“清空增量缓存”只用于修改策略后的全量复查。全库不要使用覆盖模式。

## 配置项

- **启用插件**：启用 Cron 定时任务。
- **立即运行一次**：保存后触发一次任务，随后自动关闭。
- **预演模式**：不写 NFO 或图片。
- **增量扫描**：跳过成功且未变化的目标。
- **下次忽略增量缓存**：下一轮强制处理候选，随后自动关闭。
- **发送运行摘要**：推送本次统计。
- **覆盖模式**：推荐“仅补齐缺失元数据”。
- **执行周期**：5 位 Cron 表达式。
- **单次最多处理目标**：批次上限；`0` 为不限量。
- **目标间隔**：每个目标之间的等待秒数。
- **异常重试次数**：失败后的额外尝试次数。
- **完整复核间隔**：成功目标再次处理前的天数；`0` 为关闭。
- **刮削路径**：每行一个绝对路径，支持 `#电影`、`#电视剧` 后缀。
- **排除路径**：跳过指定路径及子路径。
- **清空增量缓存**：下一轮重新处理所有候选，仅按需使用。

## NFO 精细修复计划

已有 NFO 中的空概要或“第 N 集”通用标题不属于当前缺失文件检测范围。后续将提供独立、可预演、带内容指纹缓存的空白字段与可疑标题修复，不使用全局覆盖模式。

## 初次验证

1. 保持“预演模式”，只填写一个小目录。
2. 执行一次并查看运行摘要。
3. 关闭预演后再次执行，检查已有 NFO 未被改写。
4. 扩大扫描范围，并在启用定时任务前停用官方插件。

完整安装说明和版本记录见仓库根目录 `README.md` 与 `package.v2.json`。
