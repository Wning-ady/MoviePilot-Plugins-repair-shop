# LibraryScraperFix

MoviePilot V2“媒体库刮削”安全增量修复版，基于官方 `LibraryScraper 2.1.3`。

## 核心行为

- 默认停用、默认预演，不会在安装后自动写媒体库。
- 不覆盖模式只补齐缺失项，即使 MoviePilot 全局 NFO 策略设为覆盖。
- 全程应用排除路径、强制媒体类型和符号链接保护，包括目录识别失败后的文件回退。
- NFO 中的 TMDB ID 只有在可解析为正整数时才覆盖文件名解析结果。
- 只缓存完整成功的目录；部分成功、未识别和失败目标会在下次任务继续尝试。
- 组合指纹包含文件路径、大小和纳秒修改时间；默认每 7 天完整复核一次。
- 进程内锁、跨热重载文件锁及 MoviePilot 刮削锁共同阻止并发写入。

## 初次验证

1. 保持“预演模式”，只填写一个小目录。
2. 执行一次并查看运行摘要。
3. 关闭预演后再次执行，检查已有 NFO 未被改写。
4. 扩大扫描范围，并在启用定时任务前停用官方插件。

完整安装说明和版本记录见仓库根目录 `README.md` 与 `package.v2.json`。
