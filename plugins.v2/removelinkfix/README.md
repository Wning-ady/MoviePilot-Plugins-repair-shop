MoviePilot V2 插件“清理媒体文件（修复版）”的源码目录。

- 插件 ID：`RemoveLinkFix`
- 配置前缀：`removelinkfix_`
- 上游基础：DzAvril `RemoveLink 2.16`
- 市场索引：`../../package.v2.json`

## 2.18 删除安全规则

- 媒体库目标文件或目录删除不会反向删除下载源、种子或转移记录。
- NFO、图片、字幕等刮削文件删除不会进入媒体联动队列。
- 只有精确下载源路径命中唯一成功的 `link` 转移记录时才建立删除任务。
- 延迟到期或立即执行前都会复核记录 ID、源路径、目标路径、下载 hash、inode 和硬链接数。
- 只删除转移记录指向的精确目标，不再遍历删除全部同 inode 路径。
- 种子联动事件只发送一次，且必须携带转移记录中的源路径和下载 hash。
- 无记录、失败记录、非硬链接模式、记录变化、目标被替换或存在额外硬链接时保留现场并写入日志。

安装和验证步骤请参阅仓库根目录的 `README.md`。
