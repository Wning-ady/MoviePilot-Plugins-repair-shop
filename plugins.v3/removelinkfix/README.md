# RemoveLinkFix V3

MoviePilot V3 插件“清理媒体文件（修复版）”的源码目录。

- 插件 ID：`RemoveLinkFix`
- V3 版本：`3.1.2`
- 配置前缀：`removelinkfix_`
- 上游基础：DzAvril `RemoveLink 2.16`
- 市场索引：`../../package.v3.json`

## 安全规则

- 媒体库目标文件或目录删除不会反向删除下载源、种子或转移记录。
- NFO、图片、字幕等刮削文件删除不会进入媒体联动队列。
- 只有精确下载源路径命中唯一成功的 `link` 转移记录时才建立删除任务。
- 延迟到期或立即执行前都会复核记录 ID、源路径、目标路径、下载 hash、inode 和硬链接数。
- 只删除转移记录指向的精确目标，不遍历删除全部同 inode 路径。
- 种子联动事件只发送一次，且必须携带转移记录中的源路径和下载 hash。
- 无记录、失败记录、非硬链接模式、记录变化、目标被替换或存在额外硬链接时保留现场并写入日志。
- 删除整理记录后按精确记录 ID 回查，只有记录已不存在才显示“已删除”；删除无效或回查异常显示“仍保留”。
- 插件结果页按完整批次展示记录 ID、集数、源路径、整理记录状态和种子联动状态；失败、保留和联动异常记录优先显示，明细表默认收起。
- 队列日志“从延迟删除队列移除 N 个已完成任务”只表示任务出队，不代表删除了 N 条整理记录。

## Vue 联邦页面

V3 `3.1.2` 使用 Vue 联邦页面替代单一 JSON 结果页；页面不注册 MoviePilot 左侧导航入口：

- 页面入口：从插件市场打开 **清理媒体文件（修复版）** 的详情页，或直接访问插件页面。
- 联邦暴露：`./Page`、`./Config`、`./AppPage`。
- 数据接口：`GET /api/v1/plugin/RemoveLinkFix/history`，使用宿主 Bearer 认证。
- 页面显示最近 20 个删除批次；每批最多保存 200 条明细。
- 批次页先显示处理数量、真实删除文件数、整理记录状态和种子联动状态，再显示可搜索、可筛选的明细表。
- 每条删除任务显示自己的完成时间；旧批次缺少任务时间时回退到批次完成时间。
- 失败、仍保留、缺少 Hash 和未发送等问题优先显示；源文件长路径自动换行，明细表默认收起。

前端源码位于 `frontend/src/remove/`，构建产物位于 `plugins.v3/removelinkfix/dist/assets/`。在仓库根目录执行：

```bash
npm ci --prefix frontend
npm run build --prefix frontend
python3 .github/scripts/check_federation_css.py
```

## 安装后检查

1. 停用原版“清理媒体文件”，避免同一目录被两个插件同时监控。
2. 刷新插件市场并安装 `3.1.2`。
3. 从插件市场详情页打开结果页面；插件不会出现在左侧导航。
4. 先用一个可重新下载的小样本验证：源文件、硬链接目标、整理记录、Hash、inode、通知和结果页状态必须一致。

V3 实现使用 MoviePilot V3 的 `app.sdk` 日志、配置和事件入口；运行前建议先停用旧版 V2 插件，避免两个版本同时监控同一目录。

安装和验证步骤请参阅仓库根目录的 `README.md`。
